说明：repository.kodi2fntv.git 走 GitHub Pages，repository.kodi2fntv.cf 走 Cloudflare；两个库装的插件完全一样，任选其一安装即可，不要同时装。已装旧版 repository.kodi2fntv.media（1.0.7 / 1.0.8）的继续可用，也可卸载后换新版。装完若「从库安装」提示“无法连接到库”，请先到 「插件 → 我的插件 → 插件库」选中本库，按菜单键执行一次「检查更新」，等待完成后再次进入「从库安装」即可（无需重启 Kodi）。
